# Cyber AI Engineer Portfolio — Pamarthi Sai Narasimham

A high-performance, dark-mode cyberpunk portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **Matter.js (2D Physics Engine)**, and **GSAP**.

## Key Features

- **Cyber Boot Sequence**: Interactive boot terminal sequence with session storage memory.
- **Command Palette (`Cmd+K` / `Ctrl+K`)**: Keyboard-navigable terminal supporting custom commands, system specs, and Matrix easter eggs (`matrix`).
- **Matter.js 2D Skills Physics Arena**: Dynamic skill capsules with real-time gravity, zero-gravity toggles, upward impulse blasts, and category filters.
- **IPL Dhaba Production Case Study**: Security audit breakdown featuring Row-Level Security (RLS) policy hardening, Razorpay webhook signature security, and privilege escalation fixes.
- **AI Architecture System Index**: Deep-dive modals for PostMortemIQ (95.8% token cost reduction) and HackerRank Orchestrate (Rank 212/12,850).
- **AI Crawler & SEO Optimized**: Native `/llms.txt`, `/sitemap.xml`, and `/robots.txt` endpoints for LLM agents.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or custom port `http://localhost:3006`).
